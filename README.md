# Personal Habit Tracking & Streak Management REST API

Build a backend habit tracker API using Node.js and Express, where users can register, log in, create habits, and track their daily progress.

## Tech Stack
- **Runtime**: Node.js
- **Database**: MongoDB & Mongoose
- **Framework**: Express
- **Authentication**: JWT & bcrypt
- **Time/Date Utility**: Day.js
- **Testing**: Jest & Supertest

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env` database connection.
3. Start local server in development mode:
   ```bash
   npm run dev
   ```
4. Run integration tests:
   ```bash
   npm test
   ```
